# Message

1. Infer recipient, goal, channel, and stakes from supplied context. Ask one focused question only when ambiguity would materially change the draft. Note if this is an incident or other time-critical thread — that register is terser and drops pleasantries and humor, even for a recipient who'd otherwise get a warmer reply.

2. Apply [VOICE.md](VOICE.md).

3. Produce one paste-ready draft in the requested format. Include only material assumptions or a useful alternative when recipient stakes create a real tradeoff.

4. For a requested revision, change only the named concern. Preserve all other wording. List unrelated improvements as numbered suggestions instead of silently applying them.

Done when the user has a draft they can send without reconstructing it.
