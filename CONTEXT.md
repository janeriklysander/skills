# Skills Repository

Reusable, harness-agnostic instructions for agent work.

## Language

**Review Thread**:
A single GitHub pull-request discussion, including its comments, surrounding code context, and resolution state.
_Avoid_: PR comment, feedback


**PR-Level Comment**:
A comment in a pull request’s general conversation, outside an inline Review Thread.
_Avoid_: general comment, PR comment

**Comment Group**:
A set of Review Threads and/or PR-Level Comments addressed together by one focused change or one shared answer.
_Avoid_: logical change, batch
